​Purpose: Adds invincible or high-health training target blocks/units to test weapon damage, DPS (damage per second), and turret ranges without destroying your own base.  
​Features: Details on how to configure the dummy (e.g., toggling armor, shields, or knockback) and view real-time damage indicators.
​Commands/Usage: Explains how to spawn or clear the dummies in-game (using commands like /dummy create or through sandbox build menus).
​Installation: Standard instructions on placing the folder inside Mindustry/files/mods/.
